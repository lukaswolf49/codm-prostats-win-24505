## About CODM ProStats

CODM ProStats is a browser-based dashboard for Call of Duty Mobile players who want a clearer view of their progress across profiles, ranks, weapons, and camo milestones. It focuses on presenting key game data in a compact, visual format that is easier to scan on desktop or mobile.

Built with vanilla JavaScript and designed as a responsive PWA, it works well as a lightweight companion for checking stats on the go. The layout is centered on quick access to player information, mode-specific progress, and weapon tracking without relying on a heavy app stack.

## Features

- Player profile stats display for a fast overview of account progress
- Rank tracking for MP, BR, and DMZ modes

- Offline PWA support for use after installation
- Mobile-first responsive interface for small and large screens
